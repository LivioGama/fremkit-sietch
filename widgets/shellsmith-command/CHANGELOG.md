# ShellSmith

## 1.1.0

- Supports OpenAI and Groq through the fixed-host OpenAI-compatible connection.
- Keeps suggestions as text and copies only after a separate user action.

## 1.0.0

- Suggest one shell command from a user request, then copy it only after a separate explicit action.
- Keep API credentials in Fremkit’s secret store; generated text is never executed by this widget.
