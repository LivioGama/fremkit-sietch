# Changelog

What changed for the person using this widget, version by version. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); the newest version is first, and the
entry of the version being published is what the Fremkit admin shows before an update.

## 1.0.0 — 2026-10-17

### Added
- First release on the registry. A grid of your own buttons, each one pasting a saved value into
  the field that had the keyboard focus, with an optional Return after the paste. The value is
  read from the widget's saved settings, never from the page. Needs a Fremkit with the
  `paste-pad` channel: it is not in a release yet, so the tile stays empty until one ships.
